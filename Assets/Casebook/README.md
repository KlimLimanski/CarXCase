# Дневник и настенная доска

J открывает дневник. В разделах «Улики», «Места» и «Люди» доступны обнаруженные записи, их описания, фотографии и подписи. J или Esc возвращает управление герою.

В конце вступительной сцены участка герой приходит в кабинет. На настенной доске видны все найденные улики. У каждой своя бумажка с краткой выжимкой. Подойдите и нажмите E, чтобы рассмотреть их вблизи. Esc возвращает к исследованию. Когда доступны сюжетные направления, F открывает выбор маршрута.

Сбор улик использует ClueObject и ClueJournal. Сведения о местах и людях появляются по условиям revealedBy в CarXInvestigation. Фотографии и подписи назначаются через Journal Attachments у предмета. После изменения содержимого сцен обновите каталог через Tools → Investigation → Rebuild game catalog.

Модель доски хранится в ArtSource/PrecinctCork.blend. В игру импортируется PrecinctCork.fbx.
